### Word Guessing Game (Python)

A simple command-line word guessing game built with Python.
The player tries to guess a hidden fruit-related word one letter at a time within limited attempts.

#### Features
  - Random word selection
  - Category-based hints (Fruits)
  - Limited attempts (lives system)
  - Tracks guessed letters
  - Win/Lose conditions
  - Beginner-friendly Python project
  
#### How to Play
  - The game selects a random fruit word.
  - You guess one letter at a time.
  - Correct guesses reveal the letter in the word.
  - Wrong guesses reduce your attempts.
  - You win if you guess the full word before attempts run out.
